# Flow with Melanie

Yoga and wellness one-pager for Melanie.

Live site: https://flowwithmelanie.com

## Stack

- Static HTML / CSS (vanilla, single file)
- Hosted on GitHub Pages
- Custom domain via Route 53

## Structure

```
.
├── index.html       # the whole site
├── hero-flower.jpg  # hero image
├── hero-jungle.jpg  # about section image
├── hero-yoga.jpg    # hero image
├── CNAME            # GitHub Pages custom domain
└── LICENSE          # MIT
```

## Deploy

Push to `main` and GitHub Pages rebuilds automatically within a minute.

```bash
git add .
git commit -m "your message"
git push
```
